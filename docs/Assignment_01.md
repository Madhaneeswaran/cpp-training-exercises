# Assignment 1

## Problem 1: Leap Year Checker
Write a C++ program to check if the year is a leap year or not.

## Problem 2: Function Call Counter
Write a C++ function that prints the number of times it is called. 

**Requirements:**
- The variable to count the number of times the function is called must be present inside the function

## Problem 3: Name Processing
Write a C++ program that calculates the number of bytes required to store your name. Also sort the letters of your name in alphabetical order.

**Requirements:**
- Use C style strings
