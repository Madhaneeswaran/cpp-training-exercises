## Problem 2: Student Data Management
Write a C++ program to store the data of students in a classroom.

**Requirements:**
- Student data includes: Name, Roll Number, Rank
- Add a search feature to search student data by name
- Get number of students as input
- Use Dynamic memory allocation or smart pointers to store the data

## 🧠 Memory Check
- [ ] **Bounds**: If accessing `arr[i]`, is `i < size`?
- [ ] **Pointers**: Did you initialize them to `nullptr` if not used immediately?
- [ ] **References**: Are you using references for function arguments to avoid copying?
