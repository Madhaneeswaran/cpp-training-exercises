# Assignment 7: Lambda Functions, Void Pointers, Extern C

## Problem 1: Generic Addition with Void Pointers
Write a C++ function that performs addition but accepts void pointers.

**Requirements:**
- Function gets 2 numbers as void pointers
- Function gets another parameter indicating the datatype of the numbers
- Perform addition based on the datatype passed

## Problem 2: Lambda Function as Parameter
Write 2 C++ functions demonstrating lambda usage.

**Requirements:**
- **First function**: Performs addition of 2 numbers
- **Second function**: 
  - Gets the 1st function as input (lambda function)
  - Prints the added output in console

## Problem 3: Calling C Function from C++
Write a C++ program that calls a C function to calculate the factorial of a number.

**Requirements:**
- C function declared in a separate C file
- Use `extern "C"` linkage
- Call the C function from C++ program
